# 场景路由表

## 1. 路由规则

1. 根据任务选择最贴近的主场景并完整读取。
2. 提示词可以按任务自由组合；没有完全匹配的现成场景时，可读取相近场景形成临时组合场景。
3. 只有任务确实包含独立执行目标时才叠加第二个或更多场景，不为形式加载无关规则。
4. 涉及代码、环境、测试、数据库、工具或 Claude MCP 时，再按动作读取对应渐进式规则。
