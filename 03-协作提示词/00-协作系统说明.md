# 协作提示词系统说明

## 定位

本目录是**子代理角色设置的唯一存放处（人）**，与 `07-工作流体系`（模板与规则，事）配合：ZCode 动态工作流、Paseo、cc.gui 协作模板都从这里按绝对路径引用角色 persona，不复制规则文本。

角色默认由工作流骨架或协作模板按顺序挂载；需要统一入口时用「协作-编排器」判定任务类型、档位、角色挂载和门禁。每个环节只负责自己的目标，通过交接原语把结论交给下一环节。

## 读取层级

```text
协作模板 / 协作-编排器
  -> 常驻通用规则（Paseo 已自动注入时以注入内容为准）
  -> 协作精选通用规则（所有协作角色必读）
  -> 当前角色文件（当前环节必读）
  -> 角色文件指定的主场景提示词
  -> 渐进式规则（当前动作需要时读取）
```

协作角色不自动读取：常驻通用规则全文（Paseo 注入除外）、全部主场景文件、全部渐进式规则、其他角色文件。

## 与工作流体系的关系

- 阶段投影、档位、门禁、收拢、委派四要素的结论单源：`D:\1poj\学习\智能体提示词体系\07-工作流体系\01-工作流体系设计.md`（第三、四节）。
- 交接唯一源：`D:\1poj\学习\智能体提示词体系\05-渐进式规则\10-上下文交接.md`（最小字段集：目标/事实/决定/验证/风险/下一步）。
- 角色文件首行维护版本号；修改后引用它的任务书需更新版本标记（缓存纪律见设计文档第四节）。

## 维护规则

1. 通用协作约束只写入 `02-协作精选通用规则.md`。
2. 角色的视角、挂载点、规则、输出只写入 `03-子Agent详细提示词`。
3. 立角色标准：有独立判断视角才立文件；主代理能承担的不立角色，下一阶段能兼收的不设专职。
4. 模板只写环节顺序、流程约束、门禁类型 ID 和角色名称，不重复写角色规则。
5. 旧 14 个文件（13 薄壳 Agent + 总控）已于 2026-09-20 重构为 7 角色 + 编排器；备份在 `99-历史归档\agent提示词-20260920\`。
