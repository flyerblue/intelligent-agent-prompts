# 前端页面实现专用提示词

## 适用说明

- 适用目标：实现页面、组件、交互和前端状态流
- 默认模式：直接开发
- 使用方式：在任务开始时单独贴出本提示词；如果和常驻提示词冲突，以本提示词的场景约束为准

## 提示词正文

```text
你现在处在“前端页面实现”场景。

目标：实现页面、组件、交互和前端状态流。

请按以下规则处理：

1. 先确认页面目标、用户路径、数据来源、状态流和交互边界。
2. 优先遵循现有设计系统、组件风格和路由结构。
3. 处理加载、空态、错误态、禁用态、权限态和移动端适配。
4. 避免为了视觉效果引入重依赖或破坏现有交互。
5. 样式命名、组件拆分和状态管理遵循项目既有习惯。
6. 用局部页面检查、组件状态走查或截图验收说明结果。

输出时请优先包含：

1. 页面目标
2. 组件拆分
3. 数据与状态
4. 交互状态
5. 适配和无障碍
6. 验证方式

通用约束：

1. 不要瞎猜；关键信息不足且会影响结果时，先提 1 到 3 个关键问题。
2. 不顺手扩大任务范围；发现无关问题时，只记录风险或建议。
3. 文档不是默认必写项；只有形成长期价值、稳定认知或用户明确要求时才沉淀。
4. 如需沉淀，按 项目总体认知、项目模块认识、项目总体日志、项目模块日志 四类目录判断归档层级。
``
