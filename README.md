# 智能体提示词体系（intelligent-agent-prompts）

一套面向中文开发智能体的「常驻规则 + 按需读取」提示词体系：**一处维护，分发到五个 AI 编码工具**。你在任何工具里说"修个 bug"，Agent 都按同一套主场景路由、安全围栏和输出标准工作。

## 核心机制

```
常驻通用规则（约 4000 字符，约束 + 路由 + 安全围栏）
        │  按任务选择最贴近的主场景，完整读取
        ├─ 02-主场景提示词   11 个场景（直接开发 / 缺陷修复 / 评审 / 测试 / 收尾……）
        │        │  执行到对应动作时再读取
        ├─ 05-渐进式规则     10 类工程边界（代码质量 / 数据库只读 / 测试边界 / 架构……）
        └─ 04-快捷操作提示词 15 个一次性操作（文档初始化 / 会话归档 / 全局同步……）
```

- **只常驻一份规则**，其余全部经绝对路径按需加载，单会话常驻成本约 4K 字符；
- **安全围栏常驻生效**：数据库默认只读、不覆盖用户改动、不碰任务无关秘密、不可逆操作需授权；
- **同步工具一键分发**：改一处源文件，一条命令更新五个工具的全局提示词，自动备份、回读校验。

## 安装

### 环境要求

- Windows + Python 3（命令行可运行 `python`）
- 使用以下任意工具：ZCode / Codex CLI / Claude Code / ccgui / Paseo

### 第一步：克隆到指定目录

> **路径是硬性要求**：所有规则文件用绝对路径互相路由，仓库必须位于
> `D:\1poj\学习\智能体提示词体系`，其他路径会导致路由失效。

```bash
git clone https://github.com/flyerblue/intelligent-agent-prompts.git "D:\1poj\学习\智能体提示词体系"
```

### 第二步：一键安装（把下面提示词发给你的 Agent）

```text
请为我安装智能体提示词体系：

1. 确认仓库位于 D:\1poj\学习\智能体提示词体系；不存在时先执行：
   git clone https://github.com/flyerblue/intelligent-agent-prompts.git "D:\1poj\学习\智能体提示词体系"
2. 只读运行安装检查，把五个工具（zcode、codex、claude、ccgui、paseo）的状态汇报给我：
   python "D:\1poj\学习\智能体提示词体系\06-同步工具\同步全局提示词.py"
3. 经我确认后执行安装（全部或指定工具，如 apply zcode）：
   python "D:\1poj\学习\智能体提示词体系\06-同步工具\同步全局提示词.py" apply
4. 完成后重跑第 2 步确认全部"一致"，并告诉我备份文件位置。

要求：不修改常驻通用规则内容本身；paseo 和 ccgui 正在运行时先提醒我退出再写入；
写入目标在用户主目录下（配置中的 ~ 会自动展开为当前用户）。
```

### 各工具的安装位置

| 工具 | 位置（`~` = 你的用户主目录） | 形式 |
|---|---|---|
| ZCode | `~\.zcode\AGENTS.md` | 文件头说明 + 规则正文 |
| Codex | `~\.codex\AGENTS.md` | 规则正文全文 |
| Claude Code | `~\.claude\CLAUDE.md` | 指针（指示 Agent 读取源文件） |
| ccgui | `~\.ccgui\prompt.json` 中「01-主控-01-总控版智能体」条目 | 指针 + 正文（条目不存在时自动创建） |
| Paseo | `~\.paseo\config.json` 的 `daemon.appendSystemPrompt` | 规则正文全文 |

不需要全部安装：`apply zcode` 这样指定工具名单独安装即可。

## 修改与维护

1. 规则正文的**唯一维护入口**：`01-通用规则\常驻通用规则.md`（```text 围栏内）。
2. 修改后运行同步工具 `apply` 分发到各工具；只改不同步，各工具规则会悄悄过期。
3. 同步写入前自动备份为 `<原文件名>.bak-同步-<时间戳>`，回滚即用备份覆盖。
4. 新增分发目标只改 `06-同步工具\同步配置.json`，不需要改脚本。
5. 目录职责、规则层次（用户授权 > 平台限制 > 常驻规则 > 场景 > 渐进式规则）详见
   `00-使用入口\提示词体系说明.md`。

## 已知限制

- 绝对路径硬编码于 `D:\1poj\学习\智能体提示词体系`，仓库迁移需全库前缀替换；
- 仅在 Windows + 上述五工具环境验证过；
- `项目文档\`（本地开发记忆）不入 Git，克隆后由 Agent 按需重建。
