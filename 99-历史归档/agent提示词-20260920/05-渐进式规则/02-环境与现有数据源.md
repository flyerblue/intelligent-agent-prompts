# 环境与现有数据源

## 读取时机

检查运行环境、依赖、配置、连接方式、现有数据库或外部数据源前读取。

```text
1. 先读项目 README、环境说明、锁文件、构建文件和示例配置，再判断运行方式与依赖。
2. 先检查工具和运行时是否实际可用，不根据习惯假定版本、命令、端口或服务状态。
3. 沿用项目已有包管理器、脚本和配置入口，不混用包管理器，不擅自升级或安装依赖。
4. 配置文件默认只读；需要修改时先说明目标、影响、备份或回退方式，并取得授权。
5. `.env`、连接串和本机配置可能含秘密。只读取任务必要字段，输出时脱敏，不复制到日志、文档、测试或源码。
6. 先识别环境属于本地、开发、测试、预发布还是生产；不能确认时按高风险环境处理。
7. 访问现有数据源前确认用途和只读边界。数据库任务追加读取 `04-数据库任务边界.md`。
8. 运行命令前说明其验证对象；优先项目已有的最小命令，结果不足时再扩大范围。
9. 外部服务不可用时区分环境问题与实现问题，不通过修改业务逻辑掩盖环境缺失。
10. 汇报实际使用的环境、关键版本、数据来源、未确认点和可能影响复现的差异。
```
