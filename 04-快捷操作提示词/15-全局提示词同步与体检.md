# 全局提示词同步与体检

## 操作目标

把 `01-通用规则\常驻通用规则.md` 的提示词正文，一键分发到各 AI 工具的全局提示词位置，替代手工逐个复制。同时提供只读体检模式，随时发现哪个工具的全局提示词已过期。

## 覆盖范围

| 工具 | 位置 | 形式 |
|---|---|---|
| ZCode | `C:\Users\23973\.zcode\AGENTS.md` | 文件头说明 + 正文副本 |
| Codex | `C:\Users\23973\.codex\AGENTS.md` | 纯正文副本 |
| Claude | `C:\Users\23973\.claude\CLAUDE.md` | 指针式引用源文件，不随正文变化 |
| ccgui | `C:\Users\23973\.ccgui\prompt.json` 中「01-主控-01-总控版智能体」条目 | 指针行 + 正文副本 |
| Paseo | `C:\Users\23973\.paseo\config.json` 的 `daemon.appendSystemPrompt` 字段 | 纯正文副本 |

脚本与配置位于 `D:\1poj\学习\智能体提示词体系\06-同步工具\`；新增分发目标时编辑 `同步配置.json`，不需要改脚本。

## 使用方式

```text
python "D:\1poj\学习\智能体提示词体系\06-同步工具\同步全局提示词.py"               # 检查（默认，只读）
python "D:\1poj\学习\智能体提示词体系\06-同步工具\同步全局提示词.py" apply         # 全部同步
python "D:\1poj\学习\智能体提示词体系\06-同步工具\同步全局提示词.py" apply codex  # 只同步指定目标
```

## 提示词正文

```text

向用户汇报各目标（zcode、codex、claude、ccgui、paseo）的一致状态和差异摘要；
未经用户明确确认，不执行 apply，不修改任何全局配置文件。
用户确认同步后，再运行 apply，并汇报备份位置和回读校验结果。
```

## 安全与回滚

1. apply 写入前自动备份为 `<原文件名>.bak-同步-<时间戳>`，回滚即用备份覆盖。
2. 写入后回读校验，不一致按失败报告且保留备份。
3. JSON 目标只改对应字段或条目，其余配置原样保留；比较忽略 CRLF/LF 差异。
4. paseo、ccgui 正在运行时可能回写配置，建议先退出对应程序再 apply。

## 维护规则

1. 修改 `常驻通用规则.md` 后，必须运行本脚本完成同步；只改源不同步，各工具规则会悄悄过期。
2. 修改包装（如 zcode 文件头）时编辑 `06-同步工具\包装-*.md` 模板，不要直接改目标文件。
3. 新增工具或改变全局提示词位置时，更新 `同步配置.json` 并跑一次 check 验证。
4. 备份文件确认同步成功后可定期清理，避免堆积。
