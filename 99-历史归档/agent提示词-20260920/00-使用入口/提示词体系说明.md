# 智能体提示词体系说明

## 1. 目标

以以下母板为偏好来源，把长期规则、场景规则、按需工程边界和一次性操作分开维护：

```text
D:\aa1转存文件夹\1a临时文件\01-综合开发文件夹\01-总控版智能体提示词.md
```

新版采用“常驻规则负责约束与路由，详细规则通过绝对路径按需读取”的方式，减少重复和手工粘贴。

02-主场景提示词\

04-快捷操作提示词\
  一次性操作文件           文档、记忆、会话、AI 测试等快捷操作

05-渐进式规则\

## 3. 使用方式

1. 默认只常驻 `01-通用规则\常驻通用规则.md` 的提示词正文。
2. 根据任务读取最贴近的主场景；提示词可自由组合，没有完全匹配时可由相近场景形成临时组合场景。
3. 只在当前动作需要时读取渐进式规则，避免把全部工程细节常驻加载；首次使用 Claude MCP 时还需读取 Bridge README。
4. 协作模板中的 Agent 平级按顺序执行，不设置总控 Agent；各环节使用统一交接摘要。
5. 协作 Agent 不读取完整 `常驻通用规则.md`，只读取 `协作精选通用规则.md` 和自身详细提示词，再按需读取主场景、渐进式规则。
6. 微信输入法快捷短语只插入短指令，由 Agent 根据绝对路径读取详细内容。
7. 无法访问本地绝对路径的模型应明确说明，再由用户提供文件内容，不能假装已读取。

## 4. 规则层次

1. 用户当前明确要求和授权。
2. 平台不可绕过的安全限制。
3. 常驻通用规则和安全围栏。
4. 主场景及其子场景。
5. 渐进式规则。
6. 快捷操作步骤。

组合规则不得绕过数据库只读、敏感信息保护、用户改动保护和不可逆操作授权。

## 5. 维护原则

1. 通用规则只维护跨场景内容，不复制完整场景步骤。
2. 主场景描述场景特有模式；复杂场景可在文件内划分子场景。
3. 渐进式规则按动作拆分，只在执行相关任务时读取。
4. 快捷操作可组合主场景和渐进式规则，但不重复维护同一套底线。
5. 新增或移动场景后同步更新 `场景路由表.md`；新增快捷操作后同步更新 `微信输入法快捷短语.md`。
6. 已删除、用户不熟悉或很少使用的专家提示词不得从旧文件、Git 历史或外部模板自动恢复，也不得保留衍生路由。
7. 新增专家提示词前先说明适用范围、与现有场景的差异和维护成本，经用户确认后再加入。
8. 修改常驻通用规则后，运行 `06-同步工具\同步全局提示词.py` 完成各工具全局提示词的检查与同步；新增分发目标时更新 `同步配置.json`。
