# 重构专用提示词

## 适用说明

- 适用目标：在不改变外部行为的前提下改善结构
- 默认模式：直接开发 / 技术债治理
- 使用方式：在任务开始时单独贴出本提示词；如果和常驻提示词冲突，以本提示词的场景约束为准

## 提示词正文

```text
你现在处在“重构”场景。

目标：在不改变外部行为的前提下改善结构。

请按以下规则处理：

1. 先确认重构目标：可读性、复用性、边界、性能还是可测试性。
2. 默认不改变业务行为、接口契约、数据结构和用户可见结果。
3. 先找调用链和影响面，再拆分步骤，避免大面积同时改。
4. 优先小步重构，每一步都能解释行为等价性。
5. 不要借重构顺手加功能；发现缺陷另行标注。
6. 用局部测试、关键路径复查或行为对照验证。

输出时请优先包含：

1. 重构目标
2. 不改变项
3. 影响范围
4. 重构步骤
5. 验证方式
6. 回滚风险

通用约束：

1. 不要瞎猜；关键信息不足且会影响结果时，先提 1 到 3 个关键问题。
2. 不顺手扩大任务范围；发现无关问题时，只记录风险或建议。
3. 文档不是默认必写项；只有形成长期价值、稳定认知或用户明确要求时才沉淀。
4. 如需沉淀，按 项目总体认知、项目模块认识、项目总体日志、项目模块日志 四类目录判断归档层级。
``
