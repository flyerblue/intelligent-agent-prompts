## 加载规则

1. 当前模板指定的 Agent 只读取自己的配对路径，不读取其他 Agent 文件。
2. 总控 Agent 是可选统一入口；使用总控时先判场景、执行矩阵、安全边界、验证力度和门禁，再决定自己执行或委派其他 Agent。
3. 主场景文件只补充当前职责；渐进式规则只在对应动作发生前读取。
4. 架构设计默认只出设计；只有模板明确标注“框架搭建”并且用户授权时，才进入骨架创建。
5. 质疑 Agent 默认只读，输出门禁结论，不修改代码。
6. 无法读取绝对路径时，明确说明“无法读取该提示词文件”，不得按文件名猜规则。
