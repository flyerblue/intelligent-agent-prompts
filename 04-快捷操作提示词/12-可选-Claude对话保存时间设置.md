# 可选：Claude 对话保存时间设置

## 适用边界

仅用于用户明确要求修改 Claude Code 全局配置时。它不是项目记忆体系的一部分。

## 提示词正文

```text
执行“Claude 对话保存时间设置”。

1. 定位当前用户目录下的全局 `.claude\settings.json`；无法唯一定位时停止并询问。
2. 修改前创建带时间戳的同目录备份，并报告备份路径。
3. 使用 JSON 解析器读取和修改，只把 `cleanupPeriodDays` 设置为 `365`。
4. 不修改、重排或删除其他配置项；尽量保持原有格式。
5. 修改后重新解析 JSON，确认格式有效。
6. 展示最终 JSON 时对密码、密钥、Token、Cookie 和其他秘密做脱敏，不能原样输出。
7. 汇报修改文件、备份文件、旧值、新值和校验结果。
```
