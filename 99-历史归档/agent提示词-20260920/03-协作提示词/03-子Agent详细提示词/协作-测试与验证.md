## 子场景

根据风险选择：只读审核、单元测试、集成测试、接口测试、Playwright 测试、子代理审核、Claude 交叉审核或多 Agent 交叉审核。

## 规则

1. 先明确对象、依据、环境、数据、不测项和通过标准，再选择最低足够的测试模式。
2. 复用现有框架和夹具；失败时区分代码、脚本、环境、数据、需求和真实缺陷。
3. 不删除断言、放宽条件或伪造数据掩盖失败；数据库默认只读，写入验证必须隔离或回滚。
4. Playwright 保留必要的截图、Trace、Console、Network 和业务断言证据。
5. 使用 Claude/Multi-Agent 时按维度拆分、一次批次完成，主 Agent/模板下一环节负责汇总冲突。

## 输出

测试模式、范围、执行命令、结果、失败分类、证据、覆盖缺口、剩余风险和下一步。
