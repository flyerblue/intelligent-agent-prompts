# 协作提示词系统说明

## 定位

本目录是独立的协作体系，不读取或复制旧版 Agent 的完整提示词。现有 `cc.gui` Agent 只是旧体系中“通用约束、主场景和渐进式规则”的分散拼接，不能作为新协作角色的模板。

协作模板默认由多个平级 Agent 按顺序执行；需要统一入口时，可使用 `协作-智能体总控` 先判定场景、执行矩阵、安全边界、验证力度和门禁，再按任务复杂度自主执行或编排其他协作 Agent。每个环节只负责自己的目标，并通过统一交接格式把结论交给下一环节。

## 读取层级

```text
协作模板 / 协作-智能体总控
  -> 常驻通用规则（Paseo 已自动注入时以注入内容为准）
  -> 协作精选通用规则（所有协作 Agent 必读）
  -> 当前 Agent 详细提示词（当前环节必读）
  -> 现有主场景提示词（由 Agent 文件指定）
  -> 渐进式规则（当前动作需要时读取）
```

协作 Agent 不自动读取：

- `D:\1poj\学习\智能体提示词体系\01-通用规则\常驻通用规则.md`
- 全部主场景文件
- 全部渐进式规则
- 其他 Agent 的详细提示词

## 维护规则

1. 通用协作约束只写入 `02-协作精选通用规则.md`，避免复制旧版全文。
2. Agent 的职责、输入、输出、权限和按需路径只写入 `03-子Agent详细提示词`。
3. 模板只写环节顺序、流程约束、批准点和 Agent 名称，不重复写 Agent 规则。
4. 修改规则优先修改 Markdown；`cc.gui` 的 JSON 只保存 Agent 注册信息和短加载器。
5. 不猜测 `cc.gui` 协作模板的内部持久化格式；`04-协作模板` 提供可复制的中立 JSON。
6. 任何新增 Agent 先判断是否能复用现有环节；只有职责、权限或输出明显不同才新增。
7. 总控 Agent 只负责场景、矩阵、边界、编排和门禁，不把所有专项规则复制进自身提示词。
